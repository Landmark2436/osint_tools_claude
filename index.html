OSINT Tools

Self-contained browser tools for open-source research, built with Claude Code. Each tool is a single HTML file: no installation, no backend, and your data stays in your browser, except where a tool has to ask public sources (IP & Domain Lookup).

  • Geo Triangulator

    Estimate a target's position or possible area from points with distances (radii) or leaked positions within an allowed distance (e.g. hide and seek), on an OpenStreetMap map.

    betav0.4.0
    Open tool →Documentation

  • Plate Origin

    Where does a German number plate come from? Type the first letters and see the issuing city or district and the federal state while typing.

    betav0.2.0
    Open tool →Documentation

  • IP & Domain Lookup

    Reverse DNS, network owner and the domains seen on an IP; current DNS records, registration and IP history of a domain. Queries free public sources without API keys.

    experimentalv0.1.0
    Open tool →Documentation
